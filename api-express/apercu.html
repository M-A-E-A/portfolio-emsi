Une API REST, jouable dans le navigateur

Le vrai serveur tourne en Node (npm install && npm start, puis localhost:3000). Cette page en reprend la logique à l’identique — mêmes routes, mêmes validations, mêmes codes HTTP — pour que vous puissiez la parcourir sans installer quoi que ce soit.

    Ce que le serveur fait vraiment

    Middleware

    express.json() pour lire les corps de requête, une journalisation qui chronomètre chaque appel, et un gestionnaire d’erreurs qui renvoie du JSON plutôt qu’une page HTML d’erreur.

    Validation

    Chaque écriture passe par la même fonction : nom d’au moins deux caractères, e-mail au format attendu, ville cohérente. Sinon la réponse est un 400 listant les champs fautifs.

    Codes HTTP

    200 lecture, 201 création, 204 suppression, 400 validation, 404 contact introuvable, 500 erreur inattendue.

    Sans base de données

    Les contacts vivent en mémoire. L’API démarre sans configuration ni base à installer : la démonstration porte sur Express, pas sur l’infrastructure.
