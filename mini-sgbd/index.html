Mini-SGBD

Un moteur SQL écrit à la main, sans librairie : analyse lexicale, analyse syntaxique descendante, puis exécution sur des tables en mémoire. SELECT, JOIN, GROUP BY, INSERT, UPDATE, DELETE et CREATE TABLE fonctionnent réellement. Tout se passe dans votre navigateur.

Console SQL

Écrivez une requête, puis exécutez-la. Raccourci : Ctrl + Entrée.

      Comment ça marche, et ce que c'est
      
      
      
      
      
        
      
          Une requête traverse trois étages. L'analyse lexicale découpe
          le texte en jetons (mots-clés, identifiants, nombres, chaînes, opérateurs).
          L'analyse syntaxique descendante les transforme en un arbre,
          en respectant la priorité des opérateurs. L'exécuteur parcourt
          cet arbre contre les tables. Il n'y a aucune recherche de mots-clés dans une
          chaîne : les erreurs de syntaxe sont détectées à la position exacte où elles
          se produisent.
        
      
        
      
          Les JOIN sont exécutés en boucle imbriquée, les agrégats
          (COUNT, SUM, AVG, MIN,
          MAX) regroupent les lignes, et les valeurs manquantes suivent la
          logique à trois valeurs de SQL : une comparaison avec NULL ne vaut
          ni vrai ni faux.
        
      
        
      
          À savoir : il n'y a pas de serveur, pas de réseau, et vos
          requêtes ne sont envoyées nulle part. Les tables vivent dans le
          localStorage de votre navigateur, et le contenu de démonstration
          est un jeu d'exemple écrit pour cette page. Ce moteur est une réalisation
          pédagogique, pas un SGBD de production.
