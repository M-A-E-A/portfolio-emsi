Analyse CSV

Python 3 · bibliothèque standard

Des statistiques sur un CSV, en une commande

Le script analyse.py lit un fichier CSV et affiche, colonne par colonne, le type détecté, le nombre de valeurs, les extrêmes, la moyenne, la médiane et l’écart-type. Cette page rejoue exactement le même calcul dans le navigateur, pour voir le résultat sans installer Python.

Ceci est un aperçu statique

Le vrai outil est en Python : python analyse.py donnees.csv, avec les options --groupe et --colonne. Aucun paquet à installer — uniquement la bibliothèque standard.

Ce que fait le script

      

        

          
Détection du type

          

            Si toutes les valeurs d’une colonne se convertissent en nombre, la colonne
            est dite « numérique » et reçoit min, max, moyenne, médiane et écart-type.
            Sinon elle est « texte », avec le nombre de valeurs distinctes.
          

        

        

          
Écart-type

          

            L’écart-type est calculé sur la population et non sur
            l’échantillon : c’est statistics.pstdev, cohérent avec une
            moyenne de population.
          

        

        

          
Regroupements

          

            --groupe ville calcule la moyenne d’une autre colonne
            numérique pour chaque valeur du groupe. Si aucune colonne numérique
            n’est trouvée, le script s’arrête avec un message d’erreur.
          

        

        

          
Aucune dépendance

          

            csv, argparse, statistics et
            collections — tout est dans la bibliothèque standard.
            Le fichier est lu en UTF-8 avec gestion du BOM.
