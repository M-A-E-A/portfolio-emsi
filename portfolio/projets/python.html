Le point de départ

Le portfolio affiche Python dans ses compétences. Afficher un mot sans projet derrière, c'est une déclaration. Pour que ce soit vérifiable, il fallait un script réel, lisible, qui fait quelque chose d'utile.

L'objectif

Lire un fichier CSV et produire, pour chaque colonne, des statistiques adaptées à son type : min, max, moyenne, médiane et écart-type pour les nombres ; nombre de valeurs distinctes pour le texte. Avec possibilité de regrouper par une colonne et de moyenner une autre.

Contrainte volontaire : aucune dépendance externe. Tout tient dans la bibliothèque standard, pour que le script se lance avec un simple python analyse.py.

Ce que j'ai construit

  • Lecture d'un CSV avec csv.DictReader, gestion de l'encodage (utf-8-sig)
  • Détection automatique du type d'une colonne (numérique ou texte)
  • Statistiques : min, max, moyenne, médiane, écart-type, valeurs distinctes
  • Regroupement par une colonne avec moyenne d'une autre
  • Interface en ligne de commande avec argparse
  • Gestion des erreurs et codes de sortie
  • Fichier d'exemple inclus pour essayer immédiatement

Les difficultés

Le piège était de traiter toutes les colonnes comme du texte. Un CSV ne porte pas de types : il faut deviner. La règle retenue est simple : si toutes les valeurs d'une colonne se lisent comme des nombres, la colonne est numérique ; sinon, elle est textuelle. C'est imparfait, mais prévisible.

La détection du type doit se faire avant le calcul, sinon la moyenne d'une colonne mixte échoue silencieusement ou lève une erreur tardive.

Ce que j'en retiens

La bibliothèque standard de Python couvre l'essentiel : csv, statistics et argparse suffisent pour un outil utile. Ajouter une dépendance externe pour ce genre de tâche, c'est ajouter un point de défaillance pour rien.

Et concrètement : cette page est la preuve qu'il y a quelque chose derrière la mention Python dans la section Compétences de ce portfolio.
