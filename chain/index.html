      Les quatre briques

      Le bloc

      Il contient l’index, l’horodatage, la racine de Merkle, le hash du bloc précédent, la difficulté et le nonce. Son hash inclut tout ça : modifier une seule transaction invalide le bloc entier.

      La preuve de travail

      Le hash doit commencer par n zéros. Trouver ce nonce est coûteux ; le vérifier est immédiat. C’est ce qui rend la réécriture de l’historique coûteuse.

      L’arbre de Merkle

      Les hash des transactions sont appariés deux à deux, puis les paires de hashes, jusqu’à une seule racine. Cette racine résume toutes les transactions du bloc.

      Les signatures

      Chaque transaction est signée par ECDSA sur P-256. La signature prouve que l’adresse émettrice est bien à l’origine du transfert — sans révéler la clé privée.
